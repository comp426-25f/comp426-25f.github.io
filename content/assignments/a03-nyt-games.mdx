In this assignment, you will be recreating two famous New York Times games - [**Wordle**](https://www.nytimes.com/games/wordle/) and [**Connections**](https://www.nytimes.com/games/connections/)! ## Project Structure and Architecture

The NYT Games repository is set up with the following structure:

```html
a03
├── src
|   ├── home
|   |   ├── HomePage.tsx
|   |   └── ...
|   ├── wordle
|   |   ├── WordlePage.tsx
|   |   ├── Tile.tsx
|   |   └── ...
|   ├── connections
|   |   ├── ConnectionsPage.tsx
|   |   └── ...
|   ├── ui
|   |   └── ...
|   ├── utils
|   |   └── ...
|   └── hooks
|   |   └── ...
├── index.html / wordle.html / connections.html
├── styles.css
└── ...
```

There are three pages for this site - `/`, `/wordle`, and `/connections`. There are three HTML files for these pages. Each of these pages render the associated `Page` component.

The **`/src`** directory contains all of the TypeScript code and React components for this project. The `/src/home`, `/src/wordle`, and `/src/connections` directories contain the React components for each page / game.
    * The `HomePage` component is shown when the user navigates to `/`.
    * The `WordlePage` component is shown when the user navigates to `/wordle`.
    * The `ConnectionsPage` component is shown when the user navigates to `/connections`.
Other components exist within each directory and specify child components to our page components.

The **`/utils`** directory contains helper functions that can help you while implementing this project. Specifically, I recommend looking at `/utils/collections.ts`, which contains functions that help to mutate sets and arrays.

The **`/hooks`** and **`/ui`** directories contain some extra functionality and components from the starter code.

<Callout type="gray">
        **External APIs:**<br />

        The Wordle game will require accessing external data via an API call. The API has been created for you and is accessible at this URL: `https://comp426-apis.vercel.app/api/wordle`. The API has two endpoints:

        - `GET /api/wordle/word-validator/[word]` This endpoint determines if a provided 5-letter word is a valid guess (word exists in the dictionary). This endpoint will be used to ensure that all guesses from the user are valid words.

        - `GET /api/wordle/random-word/` This endpoint generates a random 5-letter word. This will be used at the start of the game to determine the word that the user is trying to guess.

        Remember from the asynchronous programming lecture that we can load data asynchronously using the fetch API. We can then use .then()` method of the returned promise to work with the data, like so:

        ```ts
        await fetch(`url here`)
            .then((response) => response.json())
            .then((data) => {
                // do something with the data
            });
        ```
    </Callout>
